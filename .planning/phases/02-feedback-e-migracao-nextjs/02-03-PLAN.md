1. **Criar `app/api/admin/login/route.ts`:**
   ```typescript
   import { NextRequest, NextResponse } from 'next/server'
   import { createHmac } from 'crypto'

   const COOKIE_NAME = 'admin-session'
   const MAX_AGE = 60 * 60 * 8 // 8 horas

   export async function POST(req: NextRequest) {
     const { password } = await req.json().catch(() => ({}))

     if (!password || password !== process.env.ADMIN_PASSWORD) {
       // Mensagem genérica — não revelar se senha existe
       return NextResponse.json({ error: 'Credenciais inválidas.' }, { status: 401 })
     }

     const expires = Date.now() + MAX_AGE * 1000
     const payload = String(expires)
     const sig = createHmac('sha256', process.env.ADMIN_SECRET!)
       .update(payload)
       .digest('hex')
     const token = `${payload}.${sig}`

     const res = NextResponse.json({ ok: true })
     res.cookies.set(COOKIE_NAME, token, {
       httpOnly: true,
       sameSite: 'lax',
       path: '/',
       maxAge: MAX_AGE,
       secure: process.env.NODE_ENV === 'production',
     })
     return res
   }
   ```

2. **Criar `middleware.ts`** na raiz do projeto:
   ```typescript
   import { NextRequest, NextResponse } from 'next/server'

   const COOKIE_NAME = 'admin-session'

   function isValidToken(token: string | undefined, secret: string): boolean {
     if (!token) return false
     const [payload, sig] = token.split('.')
     if (!payload || !sig) return false
     const expires = parseInt(payload, 10)
     if (Date.now() > expires) return false
     // Verificar HMAC com SubtleCrypto (Edge Runtime — sem 'crypto' Node.js)
     // Nota: comparação de strings simples aqui é suficiente para uso solo;
     // produção crítica usaria timingSafeEqual
     const expected = require('crypto').createHmac('sha256', secret).update(payload).digest('hex')
     return sig === expected
   }
   // ponytail: timingSafeEqual — adicionar quando abrir para múltiplos usuários

   export function middleware(req: NextRequest) {
     if (!req.nextUrl.pathname.startsWith('/admin')) {
       return NextResponse.next()
     }
     if (req.nextUrl.pathname === '/admin/login') {
       return NextResponse.next()
     }

     const token = req.cookies.get(COOKIE_NAME)?.value
     const secret = process.env.ADMIN_SECRET ?? ''

     if (!isValidToken(token, secret)) {
       const loginUrl = req.nextUrl.clone()
       loginUrl.pathname = '/admin/login'
       return NextResponse.redirect(loginUrl)
     }

     return NextResponse.next()
   }

   export const config = {
     matcher: ['/admin/:path*'],
   }
   ```
   > **Nota:** O middleware roda no Edge Runtime. Se `require('crypto')` não funcionar, usar `crypto.subtle` da Web Crypto API para o HMAC — ajustar na execução conforme o erro.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Internet → /feedback (UI) | Input do usuário validado client-side (básico) + server-side (Zod) + rate limiting. |
| Internet → /admin/login | Senha transmitida apenas via HTTPS (Vercel força TLS). Cookie httpOnly previne acesso JS. |
| Cookie admin-session → Middleware | HMAC com secret previne forjamento. Expiração previne sessão permanente. |
| Middleware (Edge) → /admin (Server) | Middleware valida antes de qualquer acesso. Server Component busca com service_role. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-08 | Spoofing | Cookie admin-session | High | Mitigate | HMAC-SHA256 com ADMIN_SECRET; cookie httpOnly + sameSite=lax. |
| T-02-09 | Information Disclosure | /admin sem auth | High | Mitigate | Middleware redireciona para login se cookie ausente/inválido/expirado. |
| T-02-10 | Tampering | Formulário de feedback | Low | Mitigate | Zod no servidor é a fonte da verdade; validação client é apenas UX. |
| T-02-11 | Information Disclosure | ADMIN_PASSWORD no bundle | Critical | Mitigate | Usado apenas em server route; nunca exportado sem NEXT_PUBLIC_ prefix. |
| T-02-12 | Spoofing | Timing attack no login | Low | Accept | Uso solo — comparação de string simples é aceitável agora. ponytail: timingSafeEqual quando multi-usuário. |
</threat_model>
