  <action>
Create read-only query functions for all PDI entities:

1. **fetchSkills(options?: { category?: string, type?: 'hard' | 'soft' })**:
   - Use `createPublicClient()` from lib/supabase/client.ts
   - Query `skills` table with optional filters
   - Parse JSONB `requirements` field to SkillRequirement[]
   - Return array of Skill objects matching src/types/pdi.ts interface
   - Order by category ASC, name ASC

2. **fetchMilestones(options?: { status?: Status, archived?: boolean, phase?: number | string })**:
   - Query `milestones` table with optional filters
   - Parse JSONB `objectives` and `unlockedRequirements` to proper types
   - Convert `relatedSkills` and `relatedResources` UUID arrays to string arrays
   - Return array of Milestone objects
   - Order by phase ASC, archived ASC, title ASC

3. **fetchProjects(options?: { status?: Status })**:
   - Query `projects` table with optional filters
   - Return array of Project objects
   - Order by status ASC, title ASC

4. **fetchResources(options?: { category?: string, status?: Status })**:
   - Query `resources` table with optional filters
   - Return array of Resource objects
   - Order by category ASC, name ASC

5. **fetchPersonalInfo()**:
   - Query `personal_info` table (singleton)
   - Return single PersonalInfo object or null

Each function:
- Has try-catch with error logging
- Returns `{ data: T[], error: string | null }` shape
- Uses typed Supabase query builder with Database type from lib/supabase/types.ts
- Includes JSDoc comment with usage example

Export all functions as named exports.
