<task type="auto">
  <name>Task 2: Create request validation helper</name>
  <files>lib/api/validation.ts</files>
  <action>
Create lib/api/validation.ts with request validation helper per research pattern.

Function to implement:

validateRequest<T>(req: NextRequest, schema: z.ZodSchema<T>): Promise<ValidationResult<T>>

Where ValidationResult<T> is:
  | { success: true; data: T }
  | { success: false; response: NextResponse }

Implementation:
1. Parse JSON body from req.json(), catch parsing errors
2. If body is null/undefined, return { success: false, response: apiError('Payload inválido', 400) }
3. Validate body with schema.safeParse(body)
4. If validation fails, return { success: false, response: apiValidationError(parsed.error) }
5. If validation succeeds, return { success: true, data: parsed.data }

Imports:
- NextRequest from 'next/server'
- z (default import) from 'zod'
- apiError, apiValidationError from './responses'

Usage pattern (add to JSDoc):
```typescript
const result = await validateRequest(req, mySchema)
if (!result.success) return result.response
const { data } = result
// ... use validated data
```

This eliminates 10+ lines of parsing/validation boilerplate per route.

Create lib/api/middleware.ts with rate limiting middleware per research pattern.

Function to implement:

withRateLimit(req: NextRequest, handler: (req: NextRequest) => Promise<NextResponse>): Promise<NextResponse>

Implementation:
1. Extract IP using helper function getIP(req: NextRequest): string
   - Check x-forwarded-for header (split on comma, take first)
   - Fallback to x-real-ip header
   - Fallback to '127.0.0.1'
   - This matches the pattern in app/api/feedback/route.ts

2. Call ratelimit.limit(ip)
3. If !success, return apiRateLimitError(limit, remaining, reset)
4. If success, call handler(req) and return its result

Imports:
- NextRequest, NextResponse from 'next/server'
- ratelimit from '@/lib/ratelimit'
- apiRateLimitError from './responses'

Export both withRateLimit and getIP as they may be useful separately.

Usage pattern (add to JSDoc):
```typescript
export async function POST(req: NextRequest) {
  return withRateLimit(req, async (req) => {
    // ... route implementation
  })
}
```

This eliminates 15+ lines of rate limit boilerplate per route.
