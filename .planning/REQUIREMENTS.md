# PDI Requirements

## REQ-01
O PDI deve permitir o desenvolvimento de habilidades de integração de "security gates" em pipelines CI/CD de Machine Learning, como testes SAST para artefatos e escaneamento em "model registries".

## REQ-02
O PDI deve garantir a prática de modelagem de ameaças para fluxos de IA usando o MITRE ATLAS e conhecimentos base de governança.

## REQ-03
O PDI deve habilitar o implementador a projetar arquiteturas de defesa que evitem falhas específicas de IA, como 'prompt injections', configurando guardrails de runtime e validando outputs semânticos.

## REQ-04
O PDI deve cobrir práticas de "Model Supply Chain Security", auditando a integridade dos artefatos desde a obtenção de modelos base (ex. uso de formatos '.safetensors').

## REQ-05
O PDI deve providenciar ambiente para testes de segurança ofensivos (Red Teaming) contra modelos base para compreender resiliência (Adversarial ML, evasão, extração).

## REQ-06
O PDI deve desenvolver a capacidade de atuar como Especialista em Segurança (Carreira em Y), guiando a estrutura de governança (NIST AI RMF) e as diretrizes de arquitetura para a corporação.
